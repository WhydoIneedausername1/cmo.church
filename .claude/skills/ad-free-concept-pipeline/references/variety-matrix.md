# Variety Matrix (free local)

Force coverage across *message* dimensions before multiplying layouts.

## Primary quadrants (pick dominant + secondary)

| | **Pain** | **Outcome** |
|---|----------|-------------|
| **Proof-light** (curiosity / tension) | A: Problem agitation, unanswered question, “why it keeps failing” | B: Specific result tease, ritual, transformation without fake numbers |
| **Proof-heavy** (evidence) | C: Objection handling, myth-bust, “I tried X” with real proof assets | D: Social proof, stats (sourced), demos, UGC-style demonstration |

Also rotate:

- **Social proof** as mechanism (reviews, creator, “people like me”) vs vanity badges
- **Curiosity** as open loop vs clickbait (stay brand-voice)

## Weekly fill rule

Minimum for a full sprint:

1. ≥1 Pain-primary
2. ≥1 Outcome-primary
3. ≥1 Social-proof-primary
4. ≥1 Curiosity-primary
5. Remaining slots: deepen winners or test new mechanisms

## Kill near-duplicates

Treat as duplicates if **same angle + same proof type + same hook structure** even when layout changes.

Vary one axis at a time when iterating:

- Hook only
- Visual only (different stock/user photo or HTML layout)
- Format only (1:1 → 9:16)
- Proof asset only

## Format × matrix cheat sheet (free local)

| Quadrant | Strong formats |
|----------|----------------|
| Pain / curiosity | Native UI mimic (notes, iMessage) via HTML, bold typography HTML |
| Outcome | Lifestyle **user/stock** photo + HTML price/CTA, before/after *with caution*, HyperFrames demo motion |
| Social proof | Review quote (real), stats motion (HyperFrames), logo bar |
| Proof-heavy demo | Screen capture + captions, product macro **user** photo layer |

**Forbidden formats for this pack:** AI-generated stills, Kling/Veo/Seedance clips, `static-ai` full frames.

## Logging

When a concept wins/loses, note quadrant + mechanism in `learnings.md` so next week’s matrix fills gaps deliberately.

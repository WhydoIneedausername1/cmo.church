# Anti-Slop Checklist (free local)

## TOC

1. Typography & layout clusters
2. Color / grade clusters
3. Copy clusters
4. Photo / video clusters
5. Exceptions

## 1. Typography & layout clusters

Fail or rework if present without brand-true exception:

- Default fonts: **Inter / Roboto / Poppins / Space Grotesk** as display
- Tracked **ALL-CAPS eyebrows**
- Middle-dot meta lines (“Fast · Simple · Secure”)
- Centered hero + **3 feature cards** SaaS kit
- Generic gradient buttons + soft blur orbs

## 2. Color / grade clusters

- Purple–indigo mesh gradients
- Cream background + **`#D97757` terracotta** accent kits
- **Acid-green / neon on black** “AI startup” kits
- Teal–orange cinematic grade on feed-native UGC briefs
- Identical soft gray card elevation everywhere

## 3. Copy clusters

- Unlock / Elevate / Seamless / Next-level / Game-changer / Revolutionary
- “Introducing…” / “Discover…” cold opens (prefer customer language)
- Fabricated stats (“10x your…”) without source
- Fake 5-star blocks / “as seen in” logo salad without permission

## 4. Photo / video clusters

- Beauty-dish stock smile into lens (unless briefed stock)
- Perfect symmetry + HDR glow
- Watermarks, stock-site bugs left in frame
- Synthetic testimonial performance sold as real customer
- Outputs that clearly came from forbidden generative video (morphing packs, model watermarks)

## 5. Exceptions

Allowed only when:

1. Confirmed in `brand-dna.md` as brand-true, **or**
2. Brief explicitly tests a native-platform mimic that requires the pattern, **and**
3. Human approves the exception on the brief

When in doubt → kill the cluster, keep the concept’s angle. Fix via HTML/MG/asset swap — not generative APIs.
